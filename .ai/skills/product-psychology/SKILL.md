# Product Psychology

Design for human learning motivation — ethically.

## Emotional outcomes

Every major region should create one or more of:

Motivation · Momentum · Curiosity · Pride · Progress · Achievement · Focus

## Core loops

### Daily return

Cue → tiny action → clear progress → reason to return tomorrow (streak / mission)

### Competence

Visible mastery > vanity metrics. Students should feel “I am getting better,” not “I collected points.”

### Autonomy

Always offer a clear next step without trapping the learner in forced paths.

### Relatedness (light)

Team/cohort/coach presence can help — never social pressure spam.

## Principles

- Progress should be visible within the first viewport
- Reduce choice overload: one primary action
- Variable rewards sparingly; predictable mastery mostly
- Loss aversion: protect streaks gently — no guilt punishment
- Burnout detection beats grind culture
- Empty states teach the next action; never shame

## Ethical boundaries (hard)

- No fake urgency
- No infinite guilt nagging
- No hiding unsubscribe/dismiss for AI nudges
- No dark patterns that inflate time-on-site against learning health
- No childish manipulation aesthetics

## Mapping to UI

| Psychology need | Product surface |
|---|---|
| Immediate clarity | Hero daily mission |
| Competence | Mastery / skill tree |
| Habit | Streak + heatmap |
| Curiosity | Smart recommendations |
| Safety | Burnout / calm coaching |
| Pride | Sparse milestones |

## Checklist

```
Product Psychology Progress:
- [ ] Primary action obvious
- [ ] Emotion named for each section
- [ ] Habit loop present without guilt
- [ ] No dark patterns
- [ ] Supports retention + completion ethically
```
