# AI + Gamification Experience Map

## AI is embedded, not a chatbot

AI must feel proactive and product-native. Prefer inline intelligence over a separate chat page.

| Surface | Student value | Placement intent |
|---|---|---|
| AI Coach | Guidance for the next best action | Near hero / daily focus |
| Daily Mission | One clear action today | Primary hero panel |
| Smart Recommendations | What to learn next | Adaptive editorial strip |
| Weak Topic Detection | Where mastery is fragile | Progress / mastery zone |
| Learning Prediction | Likely outcome if current pace continues | Calm insight, not alarmist |
| Personalized Revision | Targeted revisit plan | After assessments / weak topics |
| Study Planner | Time-aware learning plan | Planning rail / weekly view |
| Quiz Generator | Practice from real gaps | Action attached to weak topics |
| AI Summary | Compress long lessons | Lesson / session aftermath |
| AI Flashcards | Retention loops | Revision surface |
| Performance Analysis | Meaningful patterns, not vanity charts | Journey / mastery area |
| Learning Pattern Detection | Habits that help or hurt | Soft coaching insight |
| Burnout Detection | Protect momentum | Protective, calm intervention |

Rules:

- AI is NOT a chatbot
- Every AI block must answer: “How can AI help me?”
- Insights must be actionable in one tap/click
- Never dump raw model text into the UI

## Premium gamification

No childish badges.

| System | Purpose | Tone |
|---|---|---|
| Learning Streak | Daily return ritual | Calm pride |
| XP | Effort signal | Precise, not cartoon |
| Skill Tree | Visible mastery map | Editorial / spatial |
| Mastery Levels | Depth over completion theater | Serious premium |
| Milestones | Memorable achievements | Sparse celebration |
| Learning Journey | Narrative continuity | Timeline / path |
| Progress Timeline | Recency + momentum | Chronological clarity |
| Weekly Challenges | Focused bursts | Optional intensity |
| Daily Goals | Immediate closure | Small wins |
| Learning Heatmap | Consistency evidence | Quiet analytics |
| Career Growth | Long-term identity | Future-ready, adult |

Rules:

- Celebrate progress without noise
- Yellow accent reserved for meaningful wins
- Prefer journey, mastery, and momentum over badge walls
- Gamification must increase learning — never distract from it

## Emotional outcomes

Every major region should push at least one:

- Motivation
- Momentum
- Curiosity
- Pride
- Progress
- Achievement
- Focus

## Section → question mapping

| Region | Must answer |
|---|---|
| Hero / stage | What should I do now? |
| Journey / timeline | Where am I progressing? |
| Mastery / skill | What have I achieved? |
| Goals / challenges | What is my next goal? |
| AI surfaces | How can AI help me? |
