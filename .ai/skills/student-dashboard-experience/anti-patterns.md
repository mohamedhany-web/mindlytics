# Anti-Patterns — Immediate Reject

The generated dashboard MUST NEVER look like:

- Generic AI Dashboard
- AdminLTE
- Bootstrap Cards
- Tailwind Templates
- Dribbble Dashboard Clones
- Tutor LMS
- LearnDash
- Moodle
- Traditional ERP Layouts

Instead it should feel like a premium digital product designed by a team of senior product designers.

Every generated screen must be unique.

## Hard rejects

Reject and redesign if you see:

- Grids full of identical cards
- Repetitive rectangles
- Equal-sized widgets
- KPI boxes / stat strips as the main composition
- Chatbot-first AI (floating generic chat bubble as the product)
- Childish badges / cartoon sticker gamification
- Random icons with no semantic role
- Heavy borders
- Thick shadows
- Color overload
- Crowded screens
- Random gradients
- Rainbow colors
- Neon
- Poor Arabic typography
- LTR layout mirrored into RTL
- Translated-feeling Arabic copy
- Screens that could belong to any LMS after removing the logo

## Quality control questions

Before generating any design ask internally:

Does this look AI generated?

If YES

Reject it.

Does this look like a dashboard template?

Reject it.

Can someone identify this as generated by AI?

Reject it.

Is this memorable?

If NO

Redesign it.

Every generated screen must be original.

## Brand test

If the first viewport could belong to another brand after removing the Mindlytics identity, branding is too weak.

## Template smell test

If the layout could be sold as a “Student LMS Dashboard UI Kit”, reject it.
