# Arabic Typography

Arabic is FIRST CLASS.

The product is RTL-first.

RTL is NOT mirrored LTR.

## Preferred fonts

1. IBM Plex Sans Arabic
2. Tajawal
3. Alexandria
4. Cairo

Never use poor Arabic typography or Latin-only stacks for Arabic UI.

## Hierarchy

| Role | Guidance |
|---|---|
| Display | Strong, calm, premium — personal greetings / hero |
| Title | Clear section authority |
| Subtitle | One supporting line max in dense regions |
| Body | Comfortable line-height for Arabic reading |
| Caption | Meta only; never compete with body |

## Rhythm rules

- Spacing follows 8px grid
- Give Arabic more vertical breath than typical Latin UI kits
- Avoid ultra-tight tracking on Arabic
- Prefer shorter lines in immersive reading blocks
- Headings must have strong hierarchy — never flatten type

## RTL craft

- Design for Arabic reading flow, not flipped English wireframes
- Respect content density — Arabic often needs different wrapping
- Align numbers correctly in RTL contexts (grades, XP, timers, phones)
- Arabic text should never feel translated
- Use native product phrasing; cut awkward calques

## Copy craft

- Warm, intelligent, adult
- One idea per sentence in UI chrome
- CTAs as clear verbs: ابدأ، تابع، راجع، أتقن
- Avoid childish gamification slang

## Checklist

```
Arabic Typography Progress:
- [ ] Premium Arabic font loaded/applied
- [ ] Hierarchy clear at a glance
- [ ] Line-height comfortable
- [ ] RTL logical properties
- [ ] Numbers align correctly
- [ ] Copy feels native, not translated
```

## Reject

- Inter/Roboto/Arial as Arabic UI primaries
- Mirrored LTR layouts
- Cramped Arabic captions
- Mixed random font families per section
