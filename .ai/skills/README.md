## How to use

Invoke the relevant skill when working on that surface, e.g.:

- Full student home redesign → `student-dashboard-experience` + `dashboard-experience`
- Tokens/components → `design-system` + `branding`
- AI coach / missions → `ai-learning`
- Streaks / mastery → `gamification` + `learning-journey`
- Before shipping → `design-review`

These are not UI-template generators. They enforce premium, RTL-first, memorable learning OS quality.
