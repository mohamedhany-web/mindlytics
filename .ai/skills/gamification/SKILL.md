# Gamification

No childish badges.

Create a premium achievement system that increases learning — never distracts from it.

## Systems

| System | Purpose | Tone |
|---|---|---|
| Learning Streak | Daily return ritual | Calm pride |
| XP | Effort signal | Precise, adult |
| Skill Tree | Spatial mastery map | Editorial |
| Mastery Levels | Depth over theater | Serious premium |
| Milestones | Memorable wins | Sparse celebration |
| Learning Journey | Narrative continuity | Path / timeline |
| Progress Timeline | Recency + momentum | Chronological |
| Weekly Challenges | Focused bursts | Optional intensity |
| Daily Goals | Immediate closure | Small wins |
| Learning Heatmap | Consistency evidence | Quiet analytics |
| Career Growth | Long-term identity | Future-ready |

## Design rules

- Yellow (`#FFD23F`) only for meaningful wins — never wallpaper
- Teal carries ongoing progress
- Prefer journey, mastery, momentum over badge walls
- Celebrate sparsely; silence is premium
- Numbers and Arabic labels must feel native RTL
- Never use cartoon stickers, confetti spam, or game-arcade chrome

## Behavioral loops

1. **Cue** — clear next action
2. **Action** — one frictionless learning step
3. **Reward** — meaningful progress signal
4. **Investment** — streak / mastery / journey continuity

If a mechanic has reward without learning action — cut it.

## Placement

- Streak near daily ritual / hero
- Daily goal inside “what should I do now?”
- Mastery + skill tree in achievement zone
- Heatmap / timeline in progress zone
- Challenges optional, never blocking core learning

## Reject

- Childish badge grids
- Fake urgency / dark patterns
- Vanity points with no pedagogical meaning
- Noise animations on every click

## Checklist

```
Gamification Progress:
- [ ] Mechanic tied to real learning outcome
- [ ] Premium tone (no childish chrome)
- [ ] Sparse celebration moments
- [ ] RTL-native labels/numbers
- [ ] Complements journey + AI coach
```
