# Branding

Mindlytics must feel like a premium educational product — calm, intelligent, future-ready.

## Brand personality

Modern · Intelligent · Calm · Premium · Educational · Minimal · Friendly · Future Ready

## Platform name

**Mindlytics** — hero-level signal on branded learning surfaces. Never reduce the brand to a tiny nav afterthought on first viewport.

## Color intention

| Color | Hex | Use |
|---|---|---|
| Mindlytics Teal | `#49A4A2` | Trust, progress, primary action |
| Mindlytics Yellow | `#FFD23F` | Momentum, milestone, rare celebration |
| Neutrals | `#FFFFFF #F7F9FC #EEF2F7 #1A2238 #475569` | Structure and readability |

### Never

- Random gradients
- Rainbow palettes
- Neon
- Purple-on-white AI defaults
- Generic LMS blue kits that erase brand

## Voice (Arabic-first)

- Clear, warm, adult — not childish, not corporate-ERP
- Prefer verbs of progress: أكمل، تابع، اكتشف، أتقن
- Avoid translated-feeling phrasing
- AI copy should sound like a calm coach, not a chatbot dump

## Brand tests

1. **Ownership test:** Remove the logo. Could this still be Mindlytics by color, type, and tone? If no — redesign.
2. **Swap test:** Could another LMS claim this screen? If yes — redesign.
3. **Emotion test:** Does the first viewport create calm focus + motivation? If no — redesign.

## Composition rules

- Brand or product name is a hero-level signal on branded first viewports
- No headline should overpower the brand on landing-like student entry moments
- Yellow is scarce energy, not wallpaper
- Teal carries continuity across learning journeys

- [ ] Audit copy for Arabic-native voice
- [ ] Remove decorative color noise
