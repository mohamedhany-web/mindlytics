# AI Learning

AI is NOT a chatbot.

AI is embedded into the product as proactive learning intelligence.

## Surfaces

| Surface | Student value |
|---|---|
| AI Coach | Next best guidance |
| Daily Mission | One clear action today |
| Smart Recommendations | What to learn next |
| Weak Topic Detection | Fragile mastery zones |
| Learning Prediction | Likely outcome at current pace |
| Personalized Revision | Targeted revisit plan |
| Study Planner | Time-aware plan |
| Quiz Generator | Practice from real gaps |
| AI Summary | Compress long lessons |
| AI Flashcards | Retention loops |
| Performance Analysis | Meaningful patterns |
| Learning Pattern Detection | Habit insights |
| Burnout Detection | Protect momentum |

## Product rules

- Every AI block must answer: **How can AI help me?**
- Insights must be actionable in one tap
- Never dump raw model text into UI
- Prefer inline intelligence over floating generic chat
- Tone: calm coach, not alarmist, not hype
- Burnout/prediction insights are protective and respectful
- Ground recommendations in real Mindlytics data when available

## UX patterns

1. **Insight** — one sentence, Arabic-native
2. **Why** — short evidence (topic, score, streak gap)
3. **Action** — primary CTA into lesson / quiz / revision
4. **Secondary** — dismiss / later / adjust plan

## Placement

- Coach + Daily Mission near hero
- Recommendations as adaptive editorial strip
- Weak topics + quiz generator near mastery
- Planner in weekly/journey region
- Summaries/flashcards after sessions

## Reject

- Chatbot-first experiences
- Generic “Ask AI” boxes with no context
- Fear-based predictions
- AI walls of text
- Features that cannot explain their recommendation

## Checklist

```
AI Learning Progress:
- [ ] Not a chatbot shell
- [ ] Insight → why → action
- [ ] Uses real learner context
- [ ] Arabic-native coach voice
- [ ] Proactive, calm, actionable
```
