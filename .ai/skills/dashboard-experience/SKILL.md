# Dashboard Experience

This is NOT a UI generation skill.

This is a Product Design Intelligence Skill.

Create a **learning operating system**, not a dashboard.

## Feeling target

The student should never feel they entered an admin dashboard.

Instead they should feel:

"I entered my personal learning space."

## One question per section

Every section must answer exactly one:

- What should I do now?
- What have I achieved?
- What is my next goal?
- Where am I progressing?
- How can AI help me?

If it answers none — remove or redesign.

## Layout language

Use:

- Editorial layouts
- Adaptive sections
- Hero panels
- Timeline blocks
- Immersive containers
- Asymmetrical layouts
- Fluid spacing
- Magazine-inspired composition
- OS-inspired organization

Avoid:

- Grids full of identical cards
- Repetitive rectangles
- Equal-sized widgets
- KPI boxes
- AdminLTE / Bootstrap / Tailwind dashboard clones
- Tutor LMS / LearnDash / Moodle / ERP layouts
- Generic AI dashboards / Dribbble clones

## Inspiration principles only

Apple HIG · Linear · Notion · Stripe · Arc · Spotify · Duolingo · GitHub · Steam · PlayStation UI · Figma · Framer · Raycast

Borrow principles. Never replicate layouts.

## Emotional design

Motivation · Momentum · Curiosity · Pride · Progress · Achievement · Focus

Every visual element should encourage learning.

## Required regions (student home)

1. **Hero stage** — next best action / daily mission
2. **Journey rail** — where I am progressing
3. **Mastery / achievement** — what I have achieved
4. **Goals / challenges** — next goal
5. **AI surfaces** — proactive help (not a chatbot)

## Quality gates

Before shipping any screen:

- Does this look AI generated? → Reject
- Does this look like a dashboard template? → Reject
- Can someone identify this as AI output? → Reject
- Is this memorable? If no → Redesign

Every generated screen must be unique.
