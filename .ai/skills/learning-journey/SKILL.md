# Learning Journey

Students should feel a continuous story of growth — not a pile of courses.

## Journey questions

The journey region primarily answers:

**Where am I progressing?**

Adjacent regions may answer achievement and next goal, but the journey itself is path + momentum.

## Building blocks

| Block | Role |
|---|---|
| Path / rail | Ordered sense of movement |
| Current stage | “You are here” clarity |
| Next step | Immediate continuation |
| Milestones | Sparse memorable moments |
| Mastery gates | Depth checkpoints |
| Recovery branch | Catch-up without shame |
| Career growth arc | Longer identity horizon |

## Narrative rules

- Always show past → present → next
- “Continue” must deep-link to the real next activity
- Falling behind gets a calm recovery plan, not red punishment UI
- Milestones are rare; don’t milestone everything
- Course lists alone are not a journey

## Composition

Prefer:

- Horizontal/vertical timeline blocks
- Immersive path containers
- Asymmetrical “now” emphasis
- Editorial chapter labels in Arabic

Avoid:

- Identical course cards in endless grids as the only progress UI
- Percentage soup without meaning
- Locked content theater that kills motivation

## Integration

- Pair with `gamification` for streak/XP along the path
- Pair with `ai-learning` for next-step coaching
- Pair with `analytics-visualization` for heatmap/timeline evidence
- Pair with `product-psychology` for habit continuity

## Checklist

```
Learning Journey Progress:
- [ ] Past / present / next visible
- [ ] Continue targets real activity
- [ ] Recovery path defined
- [ ] Milestones sparse + meaningful
- [ ] Feels like a story, not a catalog
```
