# Analytics Visualization

Show meaning, not metric decoration.

## Purpose filter

Every chart must answer one of:

- Where am I progressing?
- What have I achieved?
- What is my next goal?
- How can AI help me?

If it only looks “dashboard-y” — cut it.

## Preferred visual forms

| Form | Best for |
|---|---|
| Progress timeline | Momentum + recency |
| Learning heatmap | Consistency |
| Mastery bars / rings (sparse) | Topic strength |
| Skill tree / spatial map | Relationship of skills |
| Spark comparisons | Before/after revision |
| Narrative callouts | AI interpretation of the data |

## Anti-KPI rules

Avoid:

- Walls of equal KPI boxes
- Rainbow multi-charts
- 3D junk charts
- Dense admin analytics transplanted into student home
- Charts without a sentence of interpretation

## Visual language

- Teal for progress continuity
- Yellow only for milestones / outliers that matter
- Neutrals for structure
- Large whitespace around figures
- Soft guides, subtle borders
- Arabic-native axis labels and number alignment

## AI pairing

Prefer: chart + one coach sentence + one action  
Example: “موضوع الاحتمالات ضعيف — راجع درس 3 ثم اختبر نفسك”

Never leave raw charts unexplained.

## Checklist

```
Analytics Viz Progress:
- [ ] One question answered
- [ ] Interpretation + action present
- [ ] No KPI box wall
- [ ] Brand colors intentional
- [ ] RTL labels/numbers correct
```
