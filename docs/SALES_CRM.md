# CRM المبيعات (بنمط SuiteCRM)

شاشات واحدة لموظف المبيعات ومدير المبيعات والأدمن. الدور بيحدد **البيانات والإجراءات**، مش شكل النظام.

- الموظف والمدير: `/employee/crm` (أسماء الـ routes: `employee.crm.*`، middleware: `sales.staff`).
- الأدمن: `/admin/crm` (أسماء الـ routes: `admin.crm.*`).
- نفس ملف الـ routes (`app/Domains/Sales/routes/crm.php`) بيتحمّل مرتين، و`CrmScope` بيحدد النطاق.

## النطاق حسب الدور (`CrmScope`)

| | الموظف | المدير | الأدمن |
|---|---|---|---|
| العملاء والصفقات | عملاؤه | عملاء فريقه (Business Developer: كل موظفي المبيعات) | الكل، ومعاهم العملاء اللي من غير موظف |
| الطلاب | الطلاب اللي جم من عملائه (`student_user_id` أو طلب مربوط بالعميل) | نفس الكلام لعملاء فريقه | كل الطلاب |
| الأنشطة | المكلَّف بيها أو اللي أنشأها | أنشطة فريقه | الكل |
| تكليف نشاط لـ | نفسه | نفسه أو أي حد في الفريق | نفسه أو أي موظف مبيعات |
| تنفيذ النشاط (تسجيل النتيجة) | المكلَّف بيه | المكلَّف بيه | المكلَّف بيه أو الأدمن |
| تعديل الموعد أو الإلغاء | المكلَّف أو اللي أنشأه | أي نشاط في فريقه | الكل |
| تحويل عميل لموظف تاني، أو ربطه بطلب | — | ✓ | ✓ |

أي سجل خارج النطاق بيرجع 404، وأي إجراء مش مسموح بيرجع 403.

## الوحدات

| الوحدة | المقابل في SuiteCRM | المسار |
|---|---|---|
| الرئيسية | Home (Dashlets) | `/crm` |
| العملاء المحتملون | Leads | `/crm/leads`، `/crm/leads/{id}` |
| الصفقات | Opportunities | `/crm/deals`، `/crm/deals/{id}` |
| تحويل لطالب | Convert Lead | `/crm/leads/{id}/convert` |

## الأنشطة المخططة (`sales_planned_activities`)

- **اللي جاي** (مكالمة، اجتماع، مهمة) بيتسجّل في جدول `sales_planned_activities`.
- **اللي حصل** بيفضل في `sales_activities`. الجدولين منفصلين، والجدول الجديد ما غيّرش أي جدول قديم.
- **الجدولة على عميل مفتوح:**
  - لو موعد المكالمة أو الاجتماع أقرب من «المتابعة التالية» (`next_follow_up_at`)، بيبقى هو المتابعة التالية.
  - كده شاشات المتابعات القديمة وKPIs بتفضل صح.
- **التنفيذ** (`SalesPlannedActivityService::complete`):
  - **اتعملت:** بيتسجّل نشاط في `sales_activities` باسم اللي نفّذ، فيتحسب في KPIs والتقرير اليومي.
  - **نتيجة المكالمة** بتحرّك المرحلة بنفس قواعد التسجيل السريع (`SalesCallOutcomeService`)، لصاحب العميل أو الأدمن بس.
  - **ما اتعملتش:** بتتقفل من غير ما تتسجّل كتواصل.
  - **في الحالتين:** لو «المتابعة التالية» كانت موعد النشاط ده، بتنتقل لأقرب نشاط مخطط تاني (أو بتتشال).
- **الإلغاء** بيعمل نفس الحاجة في «المتابعة التالية».
- **الكاليندر** بيعرض الأنشطة المخططة، ومعاها متابعات العملاء اللي ملهاش نشاط مخطط.

## الاختبارات

`tests/Smoke/SalesCrmSmokeTest.php` بيشتغل على نسخة MySQL، وكل حاجة فيه بتترجع بعد الاختبار:

```bash
SMOKE_DATABASE=mindlytics_smoke php artisan test tests/Smoke/SalesCrmSmokeTest.php
```

بيغطي كل صفحة لكل دور، والنطاق، والجدولة، والتنفيذ (من سجل العميل لحد المرحلة)، والطلاب، والكاليندر المشترك، وإن كل روابط الشريط العلوي شغالة.
